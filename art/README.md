# 도트 아트 수정 방법

- `palette.txt`: 글자 하나 = 색 하나. `.`은 투명.
- `objects.txt`: 사물 스프라이트. `[이름] 설명 | real` 또는 `| dream` 줄 아래에 격자를 쓴다.
  - 글자 하나가 점 하나. 한 스프라이트 안에서 모든 줄의 폭이 같아야 한다.
  - 줄 끝에 ` *8` 을 붙이면 그 줄을 8번 반복한다.
- 수정한 뒤 `python3 tools/render.py` 를 실행하면 `out/sprites/<이름>.png` (게임용 원본 크기)와
  `out/sheet_objects.png` (확대 미리보기)가 다시 만들어진다. 폭이 틀리거나 없는 글자를 쓰면 어느 줄인지 알려 준다.
- 캐릭터나 타일을 추가하려면 `art/` 에 같은 형식의 새 `.txt` 파일을 만들면 된다.

규칙: 현실과 꿈은 같은 팔레트를 쓴다. 꿈 버전은 현실 사물에서 **한 군데만** 어긋나게 만든다.

## 맵 수정 방법

- `art/tiles.txt`: 바닥, 벽 같은 16×16 타일. 형식은 `objects.txt`와 같다.
- `maps/*.txt`: 맵 배치도. 글자 하나 = 타일 한 칸(20×12칸 = 320×192).
  - `legend:` 아래 한 줄이 글자 하나의 뜻이다. `글자 바닥타일 사물 사물^N` 순서. `^N`은 사물을 N점 위로 올린다(탁자 위 컵, 벽의 시계).
  - `dream:` 줄에 `cup=cup_rising` 처럼 쓰면 꿈 버전에서 그 사물만 바뀐다. 배치도는 현실과 꿈이 공유한다.
  - `map:` 아래 글자를 옮기면 가구 위치가 바뀐다.
- `python3 tools/render_maps.py` 를 실행하면 `maps/out/<이름>.png`, `<이름>_dream.png`, `preview_all.png` 가 다시 만들어진다.

## 조명과 꿈 연출

- 맵 파일의 `ambient: 0.3` 은 방의 기본 밝기(0 = 캄캄함, 1 = 조명 없음)다.
- `art/lights.txt` 에 적힌 타일/사물은 빛을 낸다(이름, 반경, 세기, 색). 손전등이나 전구를 맵에 놓으면 그 주위가 밝아진다.
- `dream_add: hands@4,8 shadow_adult@13,6` 은 꿈 버전에만 추가되는 것들이다(이름@가로칸,세로칸).
- 꿈 버전도 현실과 같은 색과 조명으로 그린다. (예전의 파스텔·일렁임 효과 코드 `dream_grade`, `wobble` 는 쓰지 않고 남겨 둠)

## 꿈 배치 (dream_map)

- 맵 파일 맨 아래 `dream_map:` 에 현실과 **같은 글자 체계**로 꿈 버전 배치를 쓴다(줄 수와 폭은 `map:` 과 같아야 함). 사물 디자인은 바꾸지 않고 위치와 개수만 바꾼다.
- 사물 이름 뒤에 `!` 를 붙이면 뒤집힌다(`chair!^26` = 위로 26점 띄운 뒤집힌 의자).

## 입체(3/4 시점) 가구: art/boxes.txt

- 가구는 **상자 부품**으로 정의한다: `box x y z w d h 색` (가로 위치, 앞→뒤 깊이 위치, 높이 위치, 가로, 깊이, 높이), `decal x y z w h 색` (앞면 무늬).
- 윗면은 밝게, 옆면은 어둡게 자동으로 칠하고 외곽선도 자동으로 그린다. 숫자만 고치면 크기와 모양이 바뀐다.
- `boxes.txt` 에 있는 이름은 `objects.txt` 의 같은 이름 평면 스프라이트를 **대체**한다. 새 입체 가구를 추가하려면 같은 형식으로 쓰면 된다.
- `python3 tools/boxes.py` 로 단독 확인(`art/out/sheet_boxes.png`), `python3 tools/render_maps.py` 로 맵에 반영.
- 사물을 맵에 올릴 때(`^N`) 식탁 위 컵처럼 얹는 높이는 식탁 윗면 높이 + 2 정도로 맞춘다.
- 아직 평면인 사물: 문, 선반, 외투, 신발, 병, 깔개, 담요, 곰 인형, 슬리퍼, 벽시계, 액자. 필요하면 같은 방식으로 바꿀 수 있다.

## 그림자

- 그림자는 **가장 가까운 광원(자기 자신 제외)에서 멀어지는 방향**으로 바닥에 눕는다. 발자국 모양이 사물 높이에 비례해 늘어나고, 광원에서 멀수록 길다.
- 그림자는 **바닥 타일 위에만** 생긴다(벽 위로 번지지 않음). 바닥 타일 이름은 `tools/render_maps.py` 의 `FLOORISH` 에 있다.
- 깔개, 담요, 슬리퍼 같은 납작한 사물과 벽에 걸린 사물에는 그림자가 없다(`tools/render_maps.py` 의 `FLAT`, `WALL_MOUNTED`).
- 이어 붙이면 이음매가 생기는 긴 가구(식탁)는 칸 단위가 아니라 `table3`, `table4` 처럼 한 장짜리 스프라이트로 만든다.

## 윤곽선

- 사물마다 스프라이트 자체의 1점 외곽선(`k`)에 더해, **조명 계산이 끝난 뒤** 사물 바깥으로 검은 외곽선 1점을 한 겹 더 그린다. 어두운 장면에서도 사물이 바닥과 분리되어 보인다.
- 끄거나 켜려면 `tools/render_maps.py` 의 `OUTER_OUTLINE` 를 `False` / `True` 로 바꾼다. 색은 같은 파일의 `img.paste((4, 3, 8, 255), ...)` 줄이다.
- 바닥과 벽 같은 타일에는 이 외곽선을 그리지 않는다(타일 무늬가 지저분해지기 때문).

## 사물 시안 승인 흐름 (tools/variants.py)

- 새 사물은 `art/variants/<묶음>_boxes.txt` (입체 상자) 또는 `<묶음>_pixels.txt` (픽셀 격자)에 `이름_A/B/C` 로 시안을 만든다.
- `python3 tools/variants.py batch1` 로 사물별 A/B/C 비교 이미지(`art/out/variants_batch1.png`)를 만든다.
- 사용자가 고른 시안만 `art/boxes.txt` / `art/objects.txt` 에 정식 이름(`chair` 등)으로 옮긴다.
