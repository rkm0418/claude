# 도트 아트 수정 방법

- `palette.txt`: 글자 하나 = 색 하나. `.`은 투명.
- `objects.txt`: 사물 스프라이트. `[이름] 설명 | real` 또는 `| dream` 줄 아래에 격자를 쓴다.
  - 글자 하나가 점 하나. 한 스프라이트 안에서 모든 줄의 폭이 같아야 한다.
  - 줄 끝에 ` *8` 을 붙이면 그 줄을 8번 반복한다.
- 수정한 뒤 `python3 tools/render.py` 를 실행하면 `out/sprites/<이름>.png` (게임용 원본 크기)와
  `out/sheet_objects.png` (확대 미리보기)가 다시 만들어진다. 폭이 틀리거나 없는 글자를 쓰면 어느 줄인지 알려 준다.
- 캐릭터나 타일을 추가하려면 `art/` 에 같은 형식의 새 `.txt` 파일을 만들면 된다.

규칙: 현실과 꿈은 같은 팔레트를 쓴다. 꿈 버전은 현실 사물에서 **한 군데만** 어긋나게 만든다.
