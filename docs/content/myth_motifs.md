# 신화·설화 모티프 후보 (「멈춘 시계」)

게임의 핵심: **사랑하는 이가 괴물로 보이는 것(지각의 뒤집힘)**, **쫓기는 이가 나무가 되는 것**, **높은 곳에서 떨어지는 아이**, **진실이 한참 뒤에 드러나는 것**.

| 이야기 | 닮은 점 | 게임에서 쓸 곳 |
|---|---|---|
| **해와 달이 된 오누이**(한국) | 어머니의 모습으로 찾아온 호랑이, 어둠 속에서 구분 못 함, 나무 위로 도망, 동아줄 | 나무 머리 추격자(어머니 모습의 괴물), 5장 탈출, 동아줄=철창/난간 |
| **펜테우스와 아가베**(에우리피데스 『바코스의 여신도들』) | 어머니가 아들을 짐승(사자)으로 보고 죽임. 정신이 돌아온 뒤에야 진실을 안다 | 반대편 장(부모 시점)의 구조: 진실이 마지막에 밝혀지는 순간 |
| **악타이온** | 사냥개들이 주인을 알아보지 못하고 쫓음(사랑하는 존재가 가해자로 보이는 지각) | 도우미 동물(토끼·고양이·곰)이 점점 의심스러워지는 단계 변화 |
| **다프네** | 쫓기다 월계수가 되어 도망 | 나무 머리 추격자/탈출의 역전(쫓기는 쪽이 나무가 되는 변주) |
| **이카로스** | 높은 곳에서의 추락, 자유에 대한 갈망 | 프롤로그 추락의 은유 |
| **줄을 뱀으로 오인함**(베단타·불교의 비유) | 어둠 속에서 밧줄을 뱀으로 본다 | 사물이 괴물로 보이는 연출의 핵심 비유, 동아줄과 연결 |
| **오르페우스와 에우리디케** | 돌아보면 잃음, 부르는 소리 | 라디오 속 부르는 목소리, 뒤돌아보지 않기 |
| **아약스** | 광기로 양떼를 적으로 보고 베어 버림 | 환각에서 현실로 돌아오는 장면 |

추천 조합: **해와 달이 된 오누이**(추격·동아줄) + **펜테우스와 아가베**(진실의 순간) + **악타이온**(도우미의 단계 변화).

## 채택: 헤라클레스의 광기와 과업 (설계 문서 §21)

| 과업 | 게임에서 |
|---|---|
| 케리네이아의 암사슴(해치지 않고 산 채로) | 도우미 동물을 다치게 하지 않는 선택 |
| 스튐팔로스의 새(청동 딸랑이 소리로 쫓음) | 라디오의 소음, 환청 |
| 레르나의 히드라(베면 두 개가 자람) | 맞설수록 불어나는 망상 |
| 네메아의 사자(무기가 안 통함) | 괴물은 싸워서 이길 수 없다, 탈출은 달아남 |
| 아우게이아스의 외양간(쌓인 것을 씻어 냄) | 집·방을 정리하는 장 |
| 케르베로스(저승에 내려가 돌아옴) | 반대편 장 |

가져오지 않는 것: 광기 속 가족을 해치는 장면, 신의 벌이라는 틀.
