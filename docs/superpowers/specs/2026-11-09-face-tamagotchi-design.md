# 얼굴 다마고치 (가칭) 설계 문서

작성일: 2026-11-09 · 갱신: 얼굴/표정 시스템과 전체 게임 시스템 반영

디자인 시안(인터랙티브): https://claude.ai/artifact/P7Qbnm6Yxvg5V4jdXJjxCE (홈, 얼굴 만들기, 표정 미리보기)

## 1. 목표와 범위

**목적**: 원하는 사진의 얼굴을 캐릭터 얼굴로 넣어 다마고치처럼 키우는 **웃음용 파티 게임**. 핵심 재미는 내 사진 얼굴이 **상황에 따라 표정을 바꾸며 반응**하는 모습과 그 장면의 공유다.

| 항목 | 결정 |
|---|---|
| 플랫폼 | 네이티브 모바일 앱 (iOS/Android), React Native(Expo) |
| 재미 구조 | 혼자 키우기 중심(버전 E). 모임 모드와 친구 시스템은 **이후 확장** |
| 얼굴 처리 | 기기 내 처리. 사진 → 얼굴/이목구비 검출 → 머리 모양에 합성 |
| 표정 | 검출된 눈/입 위치에 **겹쳐 그리는** 방식 (8종, 확장 가능) |
| 결과물 | 설계 → 구현 계획 → 프로토타입 |

**프로토타입 범위 밖(이후 확장)**: 친구/모임, 서버, 얼굴 자체 변형(워핑), 배경 자동 제거, 영상 공유, 수익화, 미니게임.

## 2. 비주얼 디자인

- **공간**: 하얀 매트 아이소메트릭 방. 소품 없음. 벽, 바닥, 두께면을 **윤곽선 없이 색 차이(6단계 흰색)**로만 구분하고 모서리는 둥글게 처리한다.
- **캐릭터**: 대두형 베이스. 귀 없음, 달걀형 큰 머리(가로 120 × 세로 108 단위), 작고 통통한 몸. 머리/몸통/다리 사이의 연결 선은 없고 **바깥 윤곽선만** 얇게(1.5) 둔다. 팔은 어깨 연결부만 열고 나머지 윤곽선이 있다.
- **기본 의상(흰색)**: 몸 형태에 맞춘 반팔 티셔츠 + 반바지. 목 폭에 맞는 둥근 목선 홈이 있고, 티셔츠와 소매는 한 벌로 이어져 연결 선이 없다. 상의 밑단은 엉덩이까지 내려오고 바지는 다리 윗부분만 보인다. 바지 가랑이는 완만한 아치.
- **화면 구성**: 상단 이름/성장 단계 + 아이콘 메뉴(얼굴, 도감, 공유, 꾸미기, 설정), 중앙 방, 하단 상태 4개(굵은 숫자+가는 막대), 행동 버튼 4개(테두리 없는 둥근 색 버튼).
- **폰트(올려주신 5종)**: Gmarket Sans Bold(이름/숫자), Freesentation Medium(단계/아이콘 라벨), LevelUp Bold(말풍선, "Z"), Paperlogy Medium(상태 이름/안내), Paperlogy ExtraBold(버튼). **상업 출시 전 각 폰트 라이선스 확인 필요.**
- **색**: 바닥/벽 흰색 계열, 캐릭터 선 `#2b2623`, 피부 `#f8d8c9`(사진이 없을 때). 버튼 `#e8a33a #e8735a #8fb4d9 #a3c28d`.

## 3. 얼굴 시스템

### 3.1 파이프라인 (모두 기기 내 실행)
1. **사진 선택**: 갤러리/카메라. 얼굴이 여러 명이면 선택 화면, 없으면 수동 영역 지정.
2. **자동 설정**: 얼굴 검출(ML Kit 계열)로 **얼굴 박스 + 눈 2개 + 입** 좌표를 얻는다. 검출이 불가능한 환경(웹 등)은 **기본 비율**(얼굴 폭 62%, 눈 ±20%, 입 +36%)로 대체한다.
3. **배치**: 얼굴 폭이 머리 칸 폭의 `84% × 확대` 가 되도록 사진을 이동/확대한다. 머리 칸은 달걀형 마스크(`50% 50% 46% 46% / 52% 52% 48% 48%`).
4. **피부색 샘플링**: 볼 위치(얼굴 중심에서 좌 17%, 아래 10%) 주변 평균색 → 표정 패치 색으로 사용.
5. **수동 설정**: 6개 슬라이더(크기, 좌우, 상하, 눈 높이, 눈 간격, 입 높이)와 "이목구비 점 보기"(눈=파랑, 입=분홍), 초기화, 자동 설정 다시 하기. 모든 좌표는 **머리 칸 대비 %**로 저장한다.
6. **저장**: 원본 사진은 저장하지 않고 **잘라낸 얼굴 이미지 + FaceProfile**만 앱 내부 저장소에 둔다.

### 3.2 데이터 모델
```ts
type Pt = { x: number; y: number };               // 사진 픽셀
interface FaceProfile {
  imageUri: string;                               // 잘라낸 얼굴 (원본 아님)
  size: { w: number; h: number };
  face: { cx: number; cy: number; fw: number };   // 얼굴 박스 중심/폭 (픽셀)
  landmarks?: { eyeL: Pt; eyeR: Pt; mouth: Pt };  // 없으면 기본 비율
  skin: string;                                   // 샘플링한 피부색
  adjust: { zoom: number; offX: number; offY: number; eyeY: number; eyeGap: number; mouthY: number };
  source: 'auto' | 'heuristic' | 'manual';
}
```

## 4. 표정(상호작용) 시스템

**원리**: 사진 얼굴의 눈/입 위에 **피부색 패치**를 덮고 그 위에 표정 도형을 그린다. 위치와 크기는 FaceProfile의 눈/입 좌표에서 파생한다(눈 크기 = 얼굴 폭의 22%, 입 크기 = 36%).

| 표정 | 눈 | 입 | 효과 | 발생 조건 |
|---|---|---|---|---|
| idle | 원본 | 원본 | 없음 | 평상시 |
| happy | ^ ^ | 웃음 | 볼터치 | 놀기 |
| hungry | 원본 | 처진 입 | 땀방울 | 배고픔 30 미만 |
| eat | 원본 | 크게 벌린 입(씹기 애니메이션) | 볼터치 | 먹이기 |
| spicy | > < | 크게 벌린 입 | 얼굴 빨개짐, 불, 땀방울 | 먹이기 중 30% |
| sleepy | 감은 눈 | 작은 입 | Zzz | 재우기 / 에너지 20 미만 |
| cry | 감은 눈 | 물결 입 | 눈물 | 기분 25 미만 |
| clean | ^ ^ | 웃음 | 반짝임, 볼터치 | 치우기 |

- **우선순위**: 행동 반응(2.4초) > 상태 기반 기본 표정(배고픔 > 졸림 > 울음) > idle.
- **레이어 순서**: 사진/기본 얼굴 → 눈/입 패치와 도형 → 얼굴 색조(spicy) → 볼터치 → 땀/눈물/Zzz/반짝임/불.
- **확장**: 놀람, 화남, 수줍음, 방귀, 재채기 등은 같은 방식(패치+도형)으로 추가한다. 표정 하나는 `{눈 모드, 입 모드, 효과 목록}` 데이터로 정의한다.
- **프로토타입 한계**: 웹 시안은 브라우저 얼굴 검출(Shape Detection) 지원 여부에 따라 자동/기본 비율로 동작한다. 실제 앱은 ML Kit으로 일관되게 처리한다.

## 5. 전체 게임 시스템

### 5.1 핵심 루프
- **순간 루프(1~2분)**: 상태 확인 → 행동 → 표정 반응 → 가끔 이벤트 → 마음에 드는 장면 공유.
- **일 단위 루프**: 알림으로 호출 → 돌봄 → 일일 미션 → 별(★) 획득 → 꾸미기.
- **장기 루프**: 성장 단계 → 도감 채우기 → 의상/방 꾸미기.

### 5.2 상태와 행동
| 상태 | 시간당 감소 | 행동 | 효과 |
|---|---|---|---|
| 배고픔(satiety) | 12 | 먹이기 | +30 |
| 기분(mood) | 8 | 놀기 | 기분 +25, 에너지 −10 |
| 에너지(energy) | 6 | 재우기 | +40 |
| 청결(clean) | 5 | 치우기 | +50 |

값은 0~100으로 고정. 초기값 80. 알은 반응이 없다.

### 5.3 성장과 방치 (죽음 없음)
- **성장**: 알 → 아기(돌봄 3회) → 어린이(20회) → 어른(60회) → 노인(150회). 단계마다 몸통 크기/비율이 바뀐다. 얼굴은 항상 사진.
- **방치**: 상태가 0이고 6시간 경과 → 삐침(sulking). 24시간 이상 접속 없음 → 가출(away). 다시 접속하면 돌아오고 상태는 50으로 리셋한다. 삐침은 행동 한 번으로 풀리며 울음 표정이 나온다.
- **시간 처리**: 마지막 접속 시각과 현재 시각 차이로 계산한다. 시계가 과거로 가면 변화 없음. 백그라운드 타이머 없이 로컬 알림을 예약한다.

### 5.4 이벤트(공유할 장면)
| 이벤트 | 조건 | 표정/연출 |
|---|---|---|
| 매운맛 폭발 | 먹이기 30% | spicy |
| 과식 | 배고픔이 100을 넘는 먹이기 | 머리 칸이 부풀음(확대 1.15) + eat |
| 졸다가 쿨쿨 | 에너지 20 미만 | sleepy |
| 눈물 바다 | 기분 25 미만 | cry |
| 삐침/가출/귀환 | 방치 규칙 | cry / 방이 비어 있음 / happy |
| 성장 | 단계 상승 | happy + 반짝임 |

이벤트 장면은 이미지로 캡처하고 워터마크를 넣어 공유한다.

### 5.4.1 안전 규칙
이벤트와 문구에 외모 비하, 혐오 소재를 쓰지 않는다. 웃음은 음식, 잠, 소동 같은 상황에서만 만든다.

### 5.5 경제와 진행 (제안, 수치는 조정 대상)
- **별(★)**: 행동 +1(하루 20까지), 이벤트 +3, 일일 미션 +5, 성장 +30.
- **일일 미션 3개**: 예) 먹이기 3번, 놀기 2번, 장면 1번 공유. 7일 연속 접속 시 특별 의상.
- **꾸미기**: 기본 흰색 의상 외에 의상(색, 후드, 점퍼 등)과 방 꾸미기(벽/바닥 색, 소품)를 별로 해금한다. 가격 30~150★.
- **도감**: 본 표정, 발생 이벤트, 성장 단계, 보유 의상을 기록한다.
- **수익화(후순위)**: 꾸미기 아이템 중심. 광고에 사용자 얼굴을 쓰지 않는다. 프로토타입에서는 구현하지 않는다.

### 5.6 이후 확장 (친구/모임)
QR로 친구를 추가해 같은 자리에서 서로의 캐릭터에 장난을 치는 방식에서 시작해, 서버 방식(친구 수락 후에만 얼굴 전달, 삭제 동기화, 신고/차단)으로 넓힌다. 현재 구조는 `pet/` 상태 모델이 UI와 분리돼 있어 붙이기 쉽다.

## 6. 앱 구조

화면: 홈, 얼굴 만들기, 도감, 공유, 설정. (프로토타입은 홈과 얼굴 만들기 중심)

| 모듈 | 책임 |
|---|---|
| `face/` | 검출, 이목구비 좌표, 크롭, 피부색 샘플링, FaceProfile 저장 |
| `expression/` | 표정 정의 데이터와 상태/행동 → 표정 선택 규칙 |
| `pet/` | 상태, 시간 경과, 성장, 방치, 이벤트 선택 (UI 의존 없음) |
| `render/` | 방/몸통/의상, 머리 칸 합성(`FaceHead`), 표정 오버레이 |
| `economy/` | 별, 미션, 해금 |
| `share/` | 장면 캡처, 워터마크, 공유 시트 |
| `notify/` | 로컬 알림 예약 |
| `storage/` | 기기 내 저장, 전체 삭제 |

`FaceHead`는 `{ photo/skin, 좌표, 표정 }`을 입력으로 받아 머리 칸 하나를 그리는 단일 컴포넌트이며, 홈과 얼굴 만들기가 같은 것을 쓴다.

## 7. 개인정보와 안전
- 첫 등록 시 "본인이거나 동의받은 사진만 사용" 확인. 얼굴 데이터는 기기 밖으로 나가지 않는다. 원본 사진은 저장하지 않는다.
- 설정에서 얼굴 데이터 전체 삭제. 공유 이미지에 워터마크.

## 8. 테스트
- `pet/`, `expression/`: 단위 테스트(시간 경과, 경계값, 시계 역행, 표정 선택 우선순위).
- `face/`: 좌표 변환(사진 → 머리 칸 %)을 순수 함수로 분리해 테스트. 검출은 실기기에서 확인, 실패 시 수동 지정 경로.
- `render/`: 웹 미리보기에서 8가지 표정을 가짜 얼굴과 기본 얼굴 위에 겹쳐 눈/입 위치가 맞는지 확인.

## 9. 성공 기준
- 사진 한 장으로 1분 안에 얼굴 캐릭터가 만들어지고, 자동 설정이 어긋나면 수동으로 바로잡을 수 있다.
- 행동 4가지와 상태에 따라 8가지 표정이 사진 얼굴 위에 자연스럽게 나온다.
- 이벤트 장면을 워터마크 이미지로 공유할 수 있다.
- 앱을 닫았다 열어도 경과 시간이 올바르게 반영되고, 죽음 없이 방치/귀환이 동작한다.
- 얼굴 데이터는 기기 밖으로 나가지 않고 설정에서 삭제할 수 있다.

## 10. 결정이 필요한 것
- 일일 미션과 별 수치, 성장 단계별 몸통 모양.
- 사진 얼굴의 헤어/윤곽을 머리 칸에 어떻게 맞출지(현재는 얼굴을 꽉 채워 잘라냄).
- 폰트 라이선스 확인.
