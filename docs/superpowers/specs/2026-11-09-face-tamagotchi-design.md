# 얼굴 다마고치 (가칭) 설계 문서

작성일: 2026-11-09

## 1. 목표와 범위

**목적**: 친구나 지인의 얼굴 사진을 넣어 다마고치처럼 키우는 **웃음용 파티 게임**. 핵심 재미는 얼굴 캐릭터의 우스꽝스러운 반응과 그 장면의 공유다.

**결정 사항**

| 항목 | 결정 |
|---|---|
| 플랫폼 | 네이티브 모바일 앱 (iOS/Android) |
| 프레임워크 | React Native (Expo). 웹 미리보기로 동작 검증 |
| 얼굴 처리 | 기기 내 처리. 얼굴만 오려내 만화 몸통에 합성 |
| 재미 구조 | 공유형 솔로 다마고치 (접근법 A) |
| 결과물 | 기획서 → 구현 계획 → 앱 프로토타입 |

**프로토타입 범위 밖 (이후 확장)**: 눈/입 인식 기반 표정 변형, 배경 자동 제거 고도화, 영상(GIF/MP4) 공유, 함께 키우는 모임형(서버/동기화), 미니게임 모음, 수익화.

## 2. 컨셉과 핵심 루프

얼굴 사진을 넣으면 그 얼굴의 만화 캐릭터가 알에서 태어난다. 사용자는 캐릭터를 돌보고, 상태에 따라 얼굴이 찌그러지거나 땀을 흘리거나 하트를 뿜는 장면이 나온다.

**한 번에 1~2분 루프**
1. 앱을 열어 상태 4가지(배고픔, 기분, 피로, 청결)를 확인한다.
2. 먹이기, 놀기, 재우기, 치우기로 부족한 것을 채운다.
3. 행동마다 얼굴 반응이 나온다. (예: 매운 음식 → 얼굴이 빨개지며 불을 뿜음)
4. 가끔 웃긴 이벤트가 터진다. (방치하면 울고, 과식하면 얼굴이 부풀어 오름)
5. 마음에 드는 장면을 캡처해 공유한다.

**성장 단계**: 알, 아기, 어린이, 어른, 노인 (5단계). 단계마다 몸통 만화체가 바뀌고, 키운 방식에 따라 몸통 종류가 갈린다. 얼굴은 항상 사진 속 그 얼굴이다.

**죽음 없음**: 영구 상실은 없다. 방치하면 삐치거나 가출했다가 돌아온다. 친구 얼굴이 사라지는 일은 파티 분위기에 맞지 않기 때문이다.

## 3. 얼굴 처리와 안전장치

**파이프라인 (모두 기기 내 실행)**
1. 사진 선택: 갤러리 또는 카메라.
2. 얼굴 검출: 온디바이스 검출(ML Kit 계열)로 위치와 기울기를 찾는다. 얼굴이 없거나 여러 명이면 안내 후 직접 선택하게 한다.
3. 오려내기: 타원형 마스크로 자르고 가장자리를 부드럽게 처리한다. 프로토타입에서는 단순 마스크.
4. 합성: 몸통 위 머리 자리에 얹는다. 크기와 각도는 성장 단계별 앵커 값으로 맞춘다.
5. 표정 표현: 얼굴 레이어에 찌그러짐, 흔들림, 확대, 색 보정(빨개짐, 창백함)을 적용하고 땀방울, 눈물, 하트 스티커를 덧붙인다.

**저장**: 오려낸 얼굴만 앱 내부 저장소에 보관한다. 원본 사진은 저장하지 않는다. 서버 전송과 계정 연동은 없다.

**안전장치**
- 첫 등록 시 "본인이거나 동의받은 사진만 사용" 확인을 받는다.
- 공유 이미지에 앱 워터마크를 넣는다.
- 외모 비하나 혐오 소재 이벤트는 만들지 않는다. 웃음은 음식, 잠, 소동 같은 상황에서만 만든다.
- 설정에서 얼굴 데이터를 한 번에 삭제할 수 있다.

## 4. 앱 구조

**화면 (프로토타입 5개)**
1. 온보딩/얼굴 등록: 사진 선택, 검출, 오려내기 미리보기, 이름 입력, 동의 확인
2. 홈: 캐릭터, 상태 게이지 4개, 행동 버튼 4개
3. 도감: 키운 캐릭터 목록과 성장 기록 (여러 얼굴 등록 가능)
4. 공유: 장면 캡처, 워터마크 합성, 공유 시트
5. 설정: 알림, 얼굴 데이터 전체 삭제, 안내문

**모듈 (각각 하나의 역할)**
- `face/`: 검출, 오려내기, 저장. 입력은 사진, 출력은 얼굴 이미지.
- `pet/`: 상태 모델, 시간 경과 계산, 성장 규칙, 이벤트 선택. UI에 의존하지 않는 순수 로직.
- `render/`: 얼굴과 몸통 합성, 표정 변형, 스티커. 입력은 펫 상태, 출력은 화면 그림.
- `share/`: 캡처, 워터마크, 공유 호출.
- `notify/`: 로컬 푸시 알림. ("부장님 얼굴이 배고파합니다" 같은 문구)
- `storage/`: 기기 내 저장 (펫 상태, 얼굴 파일).

**시간 처리**: 앱을 닫은 동안의 경과는 마지막 접속 시각과 현재 시각의 차이로 계산한다. 백그라운드 타이머는 쓰지 않고, 알림은 예상 시각에 미리 예약한다. 방치가 길면 삐침 또는 가출 이벤트가 걸린다.

**공유**: 이벤트 순간에 "공유할래요?" 버튼을 띄운다. 프로토타입은 정지 이미지, 서버 없이 OS 공유 시트만 사용한다.

## 5. 테스트 방침

- `pet/` 로직은 단위 테스트로 철저히 검증한다. (시간 경과, 상태 변화, 성장 조건, 이벤트 선택)
- `render/`와 화면은 웹 미리보기에서 직접 확인한다.
- 얼굴 검출은 실기기에 의존하므로, 프로토타입에서는 검출 실패 시 수동 영역 지정 경로를 둔다.

## 6. 성공 기준

- 사진 한 장으로 1분 안에 얼굴 캐릭터가 태어난다.
- 핵심 루프 4가지 행동과 상태 변화, 얼굴 반응이 동작한다.
- 이벤트 장면을 워터마크가 찍힌 이미지로 공유할 수 있다.
- 앱을 닫았다 열어도 경과 시간이 올바르게 반영된다.
- 얼굴 데이터는 기기 밖으로 나가지 않고, 설정에서 삭제할 수 있다.
