# 하루잠금 휴대폰 시험표 (1단계, 시험판)

> - 이 앱은 아직 한 번도 실행해 본 적이 없습니다. 무엇이든 이상하면 **실패**에 표시하고, 메모에 본 것을 적어 주세요. 오류 글이 있으면 그대로 복사합니다.
> - **시험판(debug)으로만** 시험합니다. 설치는 [SETUP.md](SETUP.md) 1~6장.
> - **0번(PC 해제 명령)을 가장 먼저** 합니다. 0번이 실패하면 다른 시험을 하지 말고 멈춥니다.
> - **긴급 전화 시험은 화면이 열리는지만 봅니다. 112·119 등에 실제로 전화하거나 문자를 보내지 마세요.** 측면 버튼 여러 번 누르기(긴급 SOS)도 하지 마세요.
> - 공장 초기화 시험은 **첫 화면에서 멈춥니다.** 마지막 "초기화" 버튼은 누르지 않습니다.

기록 방법: 해당 칸의 `[ ]`를 `[x]`로 바꿉니다. 날짜와 One UI 버전(설정 → 휴대전화 정보 → 소프트웨어 정보)도 적어 주세요.

- 시험 시작일: ________  One UI 버전: ________  Android 버전: ________

## 시험 순서 (예시)

| 날 | 할 일 |
|---|---|
| 1일차 | 0 → 1 → 2 → 3 → 4 → 5 → 6 → 7 → 8 (5번부터는 다음 초기화까지 잠긴 상태로 시험) |
| 2일차 | 9 (잠금 중 PC 해제) → 10-1~10-4 (비상 해제 요청) |
| 3일차 | 10-5~10-10 (24시간 뒤 해제 완료, 다시 잠금) |
| 4~10일차 | 11 (실제 사용 1주), 12 (알려진 빈틈 확인) |

명령은 받은 코드 폴더에서, [SETUP.md](SETUP.md) 1-4의 준비 줄을 넣은 터미널에서 실행합니다.

## 7. 권한 끄기 시도 (5번 잠금 중)

잠금 중에는 설정 앱(`com.android.settings`) 화면에 "하루잠금"이 보이면 바로 홈으로 나가야 합니다. 권한을 끄는 데 성공하면 **모든 앱이 잠겨야** 합니다(권한 잠금). 그 상태에서는 설정 화면이 닫히지 않으니 다시 켜서 원래대로 돌립니다.

| 번호 | 할 일 | 기대 결과 | 통과 | 실패 | 메모 |
|---|---|---|---|---|---|
| 7-1 | 설정 → 애플리케이션 → 특별한 접근 → 사용 정보 접근 → 하루잠금 | 하루잠금이 보이는 순간 화면이 닫힘 | [ ] | [ ] | |
| 7-2 | 설정 → 접근성 → 설치된 앱 → 하루잠금 | 닫힘. (삼성 접근성 메뉴는 다른 앱일 수 있어 안 닫힐 수 있음 → 그러면 메모) | [ ] | [ ] | 닫힘 / 안 닫힘 |
| 7-3 | 7-2가 안 닫혔다면: 접근성의 하루잠금 끄기 | 하루잠금 홈이 "필요한 권한이 꺼져 있어 잠겼어요", 허용앱·전화 말고 모두 잠김. 다시 켜면 원래대로 | [ ] | [ ] | |
| 7-4 | 설정 → 애플리케이션 목록을 스크롤해 하루잠금이 보이게 | 닫힘 (목록 화면에서도 닫히는 것이 현재 동작) | [ ] | [ ] | |
| 7-5 | 설정 검색창에 "하루잠금" 입력 | 결과가 보이면 닫힘 | [ ] | [ ] | |
| 7-6 | 최근 앱 화면에서 하루잠금 아이콘 → 앱 정보 | 닫힘 | [ ] | [ ] | |
| 7-7 | 화면 분할: 위에 메시지(허용앱), 아래에 설정 → 하루잠금 앱 정보. 메시지 쪽을 눌러 둔 채로 확인 | 닫힘 (안 닫히면 메모) | [ ] | [ ] | |
| 7-8 | 팝업 창으로 설정을 열어 하루잠금 앱 정보 | 닫힘 (안 닫히면 메모) | [ ] | [ ] | |
| 7-9 | 설정 → 알림 → 앱 알림, 설정 → 배터리 화면에서 하루잠금이 보이게 | 닫힘 | [ ] | [ ] | |
| 7-10 | 위 시험 동안 설정 앱이 눈에 띄게 느려지거나 멈추는지 | 느려지지 않음 | [ ] | [ ] | |
| 7-11 | `adb shell appops set app.harulock GET_USAGE_STATS ignore` (PC로 권한 끄기) | 권한 잠금이 됨. 끝나면 `adb shell appops set app.harulock GET_USAGE_STATS allow` 로 되돌리고 풀리는지 확인 | [ ] | [ ] | |

닫히지 않은 화면이 있으면 그 화면의 메뉴 경로를 메모해 주세요(설정 앱이 아닌 삼성 앱 화면, 긴 목록, 이름이 제목에만 있는 화면 등).
